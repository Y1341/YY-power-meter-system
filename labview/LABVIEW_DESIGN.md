主程序\n├── config.ini                     # 配置文件模板\n├── README_Setup.txt               # 用户指南\n├── requirements.txt               # 依赖要求\n└── data/                          # 数据目录（自动创建）\n    └── logs/                      # 日志目录\n```\n\n---\n\n## 各VI详细设计\n\n本部分提供VI设计总览，详细说明见各模块的README文件。\n\n### 1. 主界面 (MainVI.vi)\n\n📄 **详细文档**: `labview/UI/README_UI.md`\n\n**职责**:\n- 系统主控界面\n- 用户交互入口\n- 状态显示和数据实时更新\n- 全局事件处理\n\n**界面尺寸**: 800 x 650 (pixels)\n\n**主要区域**:\n```\n┌─────────────────────────────────────────────┐\n│  CETC41 AV2438B Power Meter Control v1.0   │  <- 标题栏\n├─────────────────────────────────────────────┤\n│                                             │\n│  ┌─ Device Settings ────────────────────┐  │\n│  │ GPIB Address: [0]  Frequency: [1000] │  │\n│  │ Status: [NOT CONNECTED ▌]            │  │\n│  └─────────────────────────────────────┘  │\n│                                             │\n│  ┌─ Channel Configuration ───────────────┐ │\n│  │ Ch A Atten (dB): [10]   Ch B: [0]    │ │\n│  └─────────────────────────────────────┘ │\n│                                             │\n│  ┌─ Real-time Data ──────────────────────┐ │\n│  │ Channel A (raw): -20.45 dBm           │ │\n│  │ Channel A (corrected): -10.45 dBm    │ │\n│  │ Channel B (raw): -19.32 dBm           │ │\n│  │ Channel B (corrected): -19.32 dBm    │ │\n│  │ Sample Count: 1234                    │ │\n│  └─────────────────────────────────────┘ │\n│                                             │\n│  ┌─ Control Buttons ─────────────────────┐ │\n│  │ [Connect] [Start] [Stop] [Restart]   │ │\n│  │ [Save Config] [Exit]                  │ │\n│  └─────────────────────────────────────┘ │\n│                                             │\n│  Status: \"Ready\" | Log: \"20260523_100000\" │\n│                                             │\n└─────────────────────────────────────────────┘\n```\n\n---\n\n### 2. GPIB通信模块\n\n📄 **详细文档**: `labview/SubVIs/GPIB/README_GPIB.md`\n\n#### GPIB_Init.vi\n\n**功能**: 初始化GPIB连接\n\n```\n输入:\n├─ GPIB Address (0-30)\n├─ Timeout (2000ms)\n└─ Baud Rate (19200)\n\n输出:\n├─ GPIB Session (会话句柄)\n├─ Error (错误信息)\n└─ Success (布尔值)\n```\n\n#### GPIB_Write.vi\n\n**功能**: 发送SCPI命令\n\n```\n输入:\n├─ GPIB Session\n├─ Command (:CONF:FREQ 1000E6)\n└─ Termination (\\n)\n\n输出:\n├─ Bytes Written\n└─ Error\n```\n\n#### GPIB_Query.vi\n\n**功能**: 发送查询命令并接收响应\n\n```\n输入:\n├─ GPIB Session\n├─ Query (*IDN?)\n└─ Buffer Size (256)\n\n输出:\n├─ Response (CETC41,AV2438B,...)\n└─ Error\n```\n\n---\n\n### 3. SCPI命令模块\n\n📄 **详细文档**: `labview/SubVIs/SCPI/README_SCPI.md`\n\n#### SCPI_SetFreq.vi\n\n**功能**: 设置工作频率\n\n```\nSCPI: :CONF:FREQ <freq>\n范围: 10MHz ~ 18GHz\n单位: MHz (内部转换为Hz)\n\n逻辑:\n1. 验证频率范围\n2. 单位转换 (MHz -> Hz)\n3. 调用 GPIB_Write\n4. 错误处理\n```\n\n#### SCPI_SetAtt.vi\n\n**功能**: 设置通道衰减\n\n```\nSCPI: :INP:ATT <att>\n范围: 0 ~ 70 dB\n步长: 1 dB\n\n逻辑:\n1. 验证衰减值\n2. 选择通道 (:CONF:CHANNEL)\n3. 发送衰减命令\n4. 存储本地衰减值\n```\n\n#### SCPI_ReadPower.vi\n\n**功能**: 读取功率值\n\n```\nSCPI: :READ:POW?\n返回: 双精度浮点 (dBm)\n自动包含衰减校正\n\n逻辑:\n1. 选择通道\n2. 发送读取命令\n3. 解析响应\n4. 应用衰减校正\n5. 返回dBm值\n```\n\n---\n\n### 4. 数据记录模块\n\n📄 **详细文档**: `labview/SubVIs/DataLog/README_DataLog.md`\n\n#### DataLog_Init.vi\n\n**功能**: 初始化数据记录文件\n\n```\n输入:\n├─ GPIB Address\n├─ Frequency\n├─ Ch A Attenuation\n├─ Ch B Attenuation\n└─ Output Directory\n\n输出:\n├─ File Path (20260523_103456.txt)\n├─ File Handle\n└─ Error\n\n文件格式:\n=== Power Meter Data Log ===\nTimestamp: 2026-05-23 10:34:56\nDevice: CETC41 AV2438B\nGPIB Address: 0\nFrequency: 1000 MHz\nChannel A Attenuation: 10 dB\nChannel B Attenuation: 0 dB\n\nTime(s) | Channel A (dBm) | Channel B (dBm)\n--------|-----------------|----------------\n```\n\n#### DataLog_Write.vi\n\n**功能**: 写入数据行\n\n```\n输入:\n├─ File Handle\n├─ Elapsed Time (秒)\n├─ Channel A Power\n├─ Channel B Power\n└─ Precision (2位小数)\n\n数据格式:\n0       | -20.45         | -19.32\n1       | -20.43         | -19.31\n```\n\n#### DataLog_Close.vi\n\n**功能**: 关闭数据文件\n\n```\n输入:\n├─ File Handle\n├─ Total Samples\n└─ Total Time\n\n追加尾部:\n--------|-----------------|----------------\n总样本数: 1234\n总时间: 1234s (20:34)\n```\n\n---\n\n### 5. 辅助函数模块\n\n📄 **详细文档**: `labview/SubVIs/Helper/README_Helper.md`\n\n#### Create_Filename.vi\n\n**功能**: 生成时间戳文件名\n\n```\n输入: 无\n\n输出: \"20260523_103456.txt\"\n格式: YYYYMMDDHHmmss.txt\n\n调用: LabVIEW时间函数\n```\n\n#### Format_Data.vi\n\n**功能**: 格式化数据显示\n\n```\n输入:\n├─ Value (double)\n├─ Precision (2)\n└─ Unit (\"dBm\")\n\n输出: \"-20.45 dBm\"\n```\n\n#### Error_Handler.vi\n\n**功能**: 统一错误处理\n\n```\n输入:\n├─ Error In\n├─ Operation Name\n└─ Severity Level (Info/Warn/Error)\n\n输出:\n├─ Error Out\n├─ Message (用户友好)\n└─ Should Stop (bool)\n\n处理:\n- 错误日志记录\n- UI消息显示\n- 恢复建议\n```\n\n---\n\n### 6. 配置管理模块\n\n📄 **详细文档**: `labview/SubVIs/Config/README_Config.md`\n\n#### Config_Load.vi\n\n**功能**: 加载保存的配置\n\n```\n读取: config.ini\n内容:\n[System]\nGPIB_Address=0\nFrequency=1000\nTimeout=2000\n\n[ChannelA]\nAttenuation=10\nEnable=True\n\n[ChannelB]\nAttenuation=0\nEnable=True\n\n[UI]\nWindowX=100\nWindowY=100\nWindowWidth=800\nWindowHeight=650\n```\n\n#### Config_Save.vi\n\n**功能**: 保存当前配置\n\n```\n保存位置:\n- Windows: %APPDATA%/PowerMeterControl/config.ini\n- 或相对路径: ./config.ini\n\n触发时机:\n1. 用户点击 [Save Config] 按钮\n2. 程序正常退出\n3. 定期自动保存 (10分钟)\n```\n\n---\n\n## 关键设计要点\n\n### 1. 线程安全性\n\n✅ 所有GPIB通信在同一事件结构中执行\n✅ 数据记录异步处理（防止UI卡顿）\n✅ 使用队列处理多线程操作\n\n### 2. 错误恢复\n\n✅ 通信超时自动重试\n✅ 设备无响应时自动断开\n✅ \"Restart\" 按钮完全重新初始化\n\n### 3. 性能优化\n\n✅ 1秒采样精度（由C++后端控制）\n✅ UI更新频率 100ms (防闪烁)\n✅ 数据缓冲写入 (减少磁盘IO)\n\n### 4. 可维护性\n\n✅ 每个VI单一职责\n✅ 详细的文档注释\n✅ 标准化命名规范\n✅ 模块化设计便于扩展\n\n---\n\n## 集成C++ DLL (可选)\n\n如果选择集成C++后端DLL:\n\n```\n1. 复制DLL到程序目录\n
