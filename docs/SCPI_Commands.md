# CETC41 AV2438B SCPI命令参考

## 概述

SCPI (Standard Commands for Programmable Instruments) 是国际标准的仪器编程命令语言。

AV2438B功率计通过SCPI命令支持远程控制。

## 通信基础

### 连接信息
- **接口**: USB转GPIB
- **通信协议**: GPIB (IEEE-488.2)
- **默认地址**: 0
- **超时时间**: 2000ms

### 命令格式

```
<COMMAND> [<parameter>]
<COMMAND>?
```

- 命令后加 `?` 表示查询
- 参数与命令之间用空格或冒号分隔
- 每条命令以换行符(\n)结束
- 命令大小写通常不敏感

### 响应格式

```
<response>\n
```

- 查询命令返回值
- 设置命令通常无响应
- 错误使用 `ERROR:...` 回复

## 通用命令

### 设备识别

| 命令 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `*IDN?` | 无 | 字符串 | 查询设备ID |
| `*RST` | 无 | 无 | 重置设备到默认状态 |
| `*CLS` | 无 | 无 | 清除错误队列 |

### 示例

```
*IDN?
// 响应: CETC41,AV2438B,ZKL00039,1.0.23

*RST
// 重置设备

*CLS
// 清除错误
```

## 配置命令

### 频率设置

| 命令 | 参数 | 范围 | 单位 | 说明 |
|------|------|------|------|------|
| `:CONF:FREQ <freq>` | 数值 | 10MHz~18GHz | Hz | 设置工作频率 |
| `:CONF:FREQ?` | 无 | - | Hz | 查询当前频率 |

### 示例

```
:CONF:FREQ 1000E6
// 设置频率为1000MHz (1GHz)

:CONF:FREQ?
// 响应: 1000000000  (返回Hz)
```

### 通道选择

| 命令 | 参数 | 范围 | 说明 |
|------|------|------|------|
| `:CONF:CHANNEL <ch>` | 1 或 2 | 1, 2 | 选择通道 |
| `:CONF:CHANNEL?` | 无 | - | 查询当前通道 |

### 示例

```
:CONF:CHANNEL 1
// 选择通道1

:CONF:CHANNEL?
// 响应: 1
```

## 输入配置命令

### 衰减设置

| 命令 | 参数 | 范围 | 单位 | 说明 |
|------|------|------|------|------|
| `:INP:ATT <att>` | 数值 | 0~70 | dB | 设置输入衰减 |
| `:INP:ATT?` | 无 | - | dB | 查询输入衰减 |

### 说明

- 衰减范围: 0~70 dB
- 步长: 1 dB
- 用于保护前级放大器，防止过载
- 衰减值会自动加到读数中

### 示例

```
:INP:ATT 10
// 设置输入衰减为10dB

:INP:ATT?
// 响应: 10
```

### 阻抗设置

| 命令 | 参数 | 选项 | 说明 |
|------|------|------|------|
| `:INP:IMP <imp>` | 字符串 | 50 或 75 | 设置输入阻抗 |
| `:INP:IMP?` | 无 | - | 查询输入阻抗 |

### 示例

```
:INP:IMP 50
// 设置阻抗为50Ω
```

## 测量命令

### 功率测量

| 命令 | 参数 | 返回值 | 单位 | 说明 |
|------|------|--------|------|------|
| `:READ:POW?` | 无 | 数值 | dBm | 单次读取功率 |
| `:MEAS:POW?` | 无 | 数值 | dBm | 测量功率 |

### 说明

- 返回值为双通道功率计的当前通道功率
- 单位为 dBm (分贝毫瓦)
- 需要先用 `:CONF:CHANNEL` 选择通道
- 衰减自动计入

### 示例

```
:CONF:CHANNEL 1
:READ:POW?
// 响应: -20.45  (表示-20.45dBm)

:CONF:CHANNEL 2
:MEAS:POW?
// 响应: -19.32
```

### 功率范围

| 频率范围 | 最小功率 | 最大功率 | 说明 |
|---------|---------|---------|------|
| 10MHz~1GHz | -60dBm | +20dBm | 标准范围 |
| 1GHz~18GHz | -50dBm | +20dBm | 高频范围 |

## 工作模式命令

### 连续测量

| 命令 | 参数 | 说明 |
|------|------|------|
| `:INIT` | 无 | 启动连续测量 |
| `:ABORT` | 无 | 停止连续测量 |

### 示例

```
:INIT
// 启动连续模式

:READ:POW?
// 读取功率（重复执行）

:ABORT
// 停止测量
```

## 实际应用示例

### 场景1: 简单功率测量

```cpp
// 初始化
*IDN?          // 查询设备ID
*RST           // 重置设备

// 配置
:CONF:FREQ 1000E6      // 设置1GHz
:CONF:CHANNEL 1        // 选择通道1
:INP:ATT 10            // 设置10dB衰减

// 测量
:READ:POW?             // 读取功率
:READ:POW?             // 再次读取
```

### 场景2: 双通道扫频测量

```cpp
// 配置通道1
:CONF:CHANNEL 1
:INP:ATT 10
:CONF:FREQ 1000E6
:READ:POW?  // 读取通道1

// 配置通道2
:CONF:CHANNEL 2
:INP:ATT 0
:CONF:FREQ 1000E6
:READ:POW?  // 读取通道2
```

### 场景3: 故障排除

```cpp
// 设备无响应
*RST           // 硬重置
*CLS           // 清除错误状态
*IDN?          // 验证恢复
```

## 错误代码

| 错误信息 | 原因 | 解决方案 |
|---------|------|----------|
| Command Error | 命令语法错误 | 检查命令格式 |
| Parameter Error | 参数超出范围 | 检查参数值 |
| Hardware Error | 硬件故障 | 重启设备 |
| Device Not Ready | 设备未就绪 | 等待预热或检查连接 |
